# 화사 스튜디오

아이폰 14 Pro로 찍은 사진을 **18 Pro처럼 밝고 또렷하게** 바꿔 주는 웹앱입니다.
`photo-brighten`(사진 화사하게)의 보정 엔진과 `photo-tone-lab`(18 Pro Lab)의 화면·저장·메타데이터 처리를 합쳤어요.

- 사진은 기기 안에서만 처리돼요 (서버 전송·계정·분석 스크립트 없음)
- 정적 파일만으로 동작해요 (HTML + CSS + JS, 빌드 없음) → GitHub Pages에 그대로 올리면 돼요
- 아이폰 Safari에서 **홈 화면에 추가**하면 앱처럼 열려요

## 쓰는 법

1. 사진을 골라요 (사진 앱에서 바로, 또는 파일에서 HEIC/JPG).
2. 가운데 막대를 좌우로 밀어 원본과 보정본을 비교해요.
3. 프리셋 4종 중 하나를 고르고, 필요하면 밝기·암부 복원·대비·따뜻함·선명도, 자동 색 맞춤, 얼굴 보정을 바꿔요.
4. 손을 떼고 잠시 기다리면 저장용 사진을 미리 만들어 둬요 (저장 버튼에 초록 테두리).
5. **사진첩에 저장** → 공유 창에서 “이미지 저장”을 누르면 사진 앱에 들어가요.

## 프리셋

| 프리셋 | 특징 |
| --- | --- |
| 18 Pro 자동 (기본) | 사진마다 흰색 기준 색 맞춤·자동 밝기·얼굴 보정. 그림자는 지켜서 뿌옇지 않게 |
| 실내·인물 | 얼굴 보정 켜고 살짝 따뜻하게, 피부결은 부드럽게, 약한 색 노이즈 정리 |
| 저조도·야간 | 전체 밝기 기준으로도 끌어올리고 암부 복원, 색 노이즈 정리 |
| 선명한 야외 | 얼굴 보정 끄고 대비·윤곽·채도를 또렷하게 |

## 보정 방식 (engine.js)

1. 작은 사본(긴 변 900px)으로 분석: 가장 밝은 무채색(흰 벽·종이)으로 색 틀어짐을 80% 바로잡고, 그 흰색이 흰색답게 밝기를 맞춰요 (최대 +0.6스톱, 야간은 더).
   노을·조명처럼 일부러 색이 강한 장면은 색 맞춤을 약하게 걸어요.
2. Lab 색 공간에서 밝은 중간톤만 올리고(그림자는 그대로), 검정점·윤곽 대비로 또렷하게.
3. 피부색 영역(옷보다 밝은 곳)을 찾아 얼굴 밝기·붉은기·살구빛을 사진마다 맞춰요. 피부 위에서는 윤곽 대비·선명하게·채도를 약하게.
4. 원본 크기는 가로줄 조각(타일)으로 나눠 처리해서 큰 사진도 메모리를 적게 써요.

## 메타데이터를 지키는 방식 (exif.js)

- **JPEG 원본**: APP1(EXIF·XMP), APP2 중 ICC 색 프로필, APP13(IPTC), COM을 그대로 옮겨요.
  EXIF 안의 Orientation은 `1`로, 픽셀 크기 태그는 실제 저장 크기로 고치고, 보정 전 그림인 EXIF 썸네일(IFD1)은 연결을 끊어요.
  Apple MakerNote는 바이트 그대로예요.
- **APP2 MPF(HDR 게인맵 등 추가 이미지 위치표)는 버려요.** 새 파일에는 그 이미지가 없어서 잘못된 위치를 가리키게 되기 때문이에요.
- **색 프로필과 실제 색을 맞춰요.** 원본이 Display P3면 그림판도 P3로 처리하고 원본 프로필을 붙여요.
  P3를 못 쓰는 브라우저에서는 sRGB로 처리하고 P3 프로필은 붙이지 않아요.
- **HEIC/HEIF 원본**: 컨테이너의 `Exif` 아이템(TIFF, Apple MakerNote 포함)을 꺼내 APP1으로 넣어요. 실패하면 읽어 낸 값으로 표준 EXIF를 새로 써요.
- **저장 전 자체 검증**: 만든 JPEG를 다시 읽어 촬영일시·기기·렌즈·노출·GPS·MakerNote·Orientation을 확인하고 화면에 보여줘요.

## 파일 구조

```
index.html     화면
styles.css     스타일 (모바일 우선, 어두운 스튜디오 톤)
js/exif.js     JPEG 세그먼트 파서·주입기, TIFF 리더/패처, HEIF Exif 추출, EXIF 생성기, 검증
js/engine.js   보정 엔진 (분석, 타일 보정, 선명하게, 색 노이즈 정리)
js/app.js      화면 로직 (불러오기·미리보기·비교 슬라이더·백그라운드 준비·저장)
manifest.json  홈 화면 앱(PWA) 설정
icon.svg, icons/  아이콘
```

## 배포 (GitHub Pages)

1. 이 폴더의 파일을 저장소 `main` 브랜치에 올려요.
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, 폴더 `/ (root)`.
3. 파일을 바꿔 올릴 때는 `index.html`의 `?v=` 숫자와 `js/app.js`의 `APP_VERSION`을 함께 올려요 (아이폰 캐시 때문).

## 알려진 한계

- 라이브 포토 움직임, HDR 밝기 정보는 새 사진에 담기지 않아요. 보정본은 원본 옆에 새 사진으로 저장돼요.
- 48MP처럼 아주 큰 사진은 Safari 그림판 한계 때문에 약 16MP로 줄여 저장하고, 화면에 표시해요.
- HEIC를 못 여는 브라우저(데스크톱 크롬 등)에서는 jsDelivr의 `heic2any`를 그때만 불러와요 (인터넷 필요).
- 보정 기본값은 실내 아기 사진으로 맞췄어요. 풍경·음식·야경 사진은 더 다듬을 여지가 있어요.
